100K — projeto inicial

O index.html é um protótipo funcional: meta de R$ 100.000 em 2027, depósito com data/observação, progresso automático, calendário completo, conquistas e exportação CSV. Os dados ficam no armazenamento local do navegador.

Para gerar um APK Android: abra o Android Studio, crie um projeto Android com uma Activity WebView e coloque index.html em app/src/main/assets/index.html; habilite JavaScript e DOM storage na WebView. Depois use Build > Build APK(s). Este ZIP contém o protótipo web, não um APK compilado.
